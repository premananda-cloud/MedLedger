# MedLedger API

A secure medical ledger management system with PoW authentication, TOTP, and granular access control.

## 🚀 Quick Start with Docker

### Prerequisites
- Docker & Docker Compose installed
- Port 8000 and 5432 available

### One-Command Setup
```bash
# Clone and setup
git clone <your-repo>
cd medledger

# Run the automated setup script
./setup.sh
