doctor guide

You can request access to patient records. You only view records when the patient grants permission.

Getting started

Registration

  • Open registration page, select "Doctor" role.
  • Enter your details and verify your email.

Log in

  • Open login page, enter credentials → you see your dashboard.

Accessing patient records

Request access

  • "Find Patient" → search by username or ID → open profile.
  • Select a record → click "Request Access".
  • Add an optional message and send the request. The patient receives a notification.

View a record after approval

  • Check your notifications.
  • Open the approved record. The system verifies the permission.
  • If valid, the record is displayed. The access is logged automatically.

Access log

  • "My Access Log" shows all records you have accessed, with status and timestamps.

If access is denied

Possible reasons:

  • No permission granted yet
  • Permission expired
  • Permission revoked
Solution: ask the patient to grant new access.
