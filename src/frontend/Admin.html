admin guide

You monitor the system and generate reports. You cannot override patient security.

System access

  • Log in with admin credentials → open admin dashboard.

What you can do

System audit

  • "System Audit" shows all events: user registrations, permission grants, access attempts, revocations.
  • Filter by time, user, or action.

Generate reports

  • "Reports" → generate compliance or access reports for audits and regulations.

Investigate suspicious activity

  • "Alerts" → review failed access attempts with details (user, time, record).

Strict limitations – you cannot

  • Override patient permissions
  • Delete audit logs
  • Grant yourself access
  • View patient private keys
  • Modify permission time windows
These restrictions are part of the system's security design.
